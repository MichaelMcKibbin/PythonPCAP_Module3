# PCAP-31-0x preparation
This repo contains examples and exercises relating to the Python Institute's [PCAP™ – Certified Associate in Python Programming](https://pythoninstitute.org/python-essentials-2) PCAP-31-0x exam preparation course offered at OpenEDG (https://edube.org/).  

It also contains some samples and solutions to exercises that are part of the PCAP-31-0x exam preparation course offered by [eCollege](https://www.ecollege.ie/).  

The code in this repo is not intended to be a teaching resource or a replacement for the official course materials, but rather a comparison option for those taking the same course who might find it useful to see another student's approach to the exercises.  

Not all examples used in the courses are replicated here, and some of the examples may have been modified to suit my own learning style and experimentation.  

If you're new to programming in Python, or programming in general, I recommend starting with the [Python Essentials 1](https://pythoninstitute.org/python-essentials-1) course.  

Programmers familiar with other languages will already understand most of the Python Essential 1 course but will find useful explanations of some of Python's unique features.
